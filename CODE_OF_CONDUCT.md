# Code of conduct

Cyberdeck is committed to a welcoming, professional, and harassment-free
community. Be respectful, assume good intent while evaluating evidence, accept
constructive feedback, and keep technical disagreement focused on the work.

Harassment, discrimination, threats, deliberate exposure of private information,
and sustained disruptive behavior are not acceptable. Maintainers may edit or
remove contributions and temporarily or permanently restrict participation when
behavior threatens the community or project.

Report conduct concerns privately through the repository owner's GitHub profile
or, when the concern involves security or private data, through the private
process in [SECURITY.md](SECURITY.md). Reports will be reviewed as promptly and
confidentially as practical.
