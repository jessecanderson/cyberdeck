# Security policy

## Reporting a vulnerability

Do not open a public issue for suspected vulnerabilities, credential exposure,
approval bypasses, sandbox escapes, unsafe path handling, or sensitive transcript
leaks. Use GitHub's private security-advisory reporting for this repository:

https://github.com/jessecanderson/cyberdeck/security/advisories/new

Include affected versions, impact, reproduction steps, and sanitized evidence.
Remove tokens, credentials, personal paths, prompts, transcripts, and proprietary
source before submitting. You should receive acknowledgement through GitHub; do
not disclose the issue publicly until a fix and disclosure plan are agreed.

Only the latest released version and the current `main` branch receive security
fixes during the project's alpha phase.
